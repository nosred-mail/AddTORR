Guia de variáveis

Referência completa para personalizar o formato dos streams no Stremio. Clique em uma variável para copiá-la.

Como usar

Instruções para personalização dos templates de stream
Use {{variavel}} nos campos LINHA 1 e LINHA 2 do editor de template. O AddTORR substitui cada token pelo valor real extraído do torrent.
Pressione Enter no campo de texto para criar uma nova linha. No Stremio, cada linha aparece separada visualmente.
Se um campo não existir no torrent (ex: sem HDR), a variável some automaticamente — sem deixar espaços extras.
{{cache}} só aparece se o torrent estiver em cache no seu serviço Debrid configurado.
